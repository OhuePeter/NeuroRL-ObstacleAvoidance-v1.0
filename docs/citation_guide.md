# Citation Guide

## Citing the repository

Repository citation metadata is available in CITATION.cff.

Suggested BibTeX entry:

```bibtex
@software{ohue_blohm_2026_neurorl_obstacle_avoidance,
  author       = {Ohue, Peter and Blohm, Gunnar},
  title        = {NeuroRL-ObstacleAvoidance-v1.0},
  year         = {2026},
  version      = {1.0.0},
  publisher    = {GitHub},
  url          = {https://github.com/OhuePeter/NeuroRL-ObstacleAvoidance-v1.0},
  license      = {MIT}
}
```

## Citing a Zenodo release

After creating a Zenodo archive, add the DOI to CITATION.cff and include this entry format:

```bibtex
@software{ohue_blohm_2026_neurorl_zenodo,
  author       = {Ohue, Peter and Blohm, Gunnar},
  title        = {NeuroRL-ObstacleAvoidance-v1.0},
  year         = {2026},
  doi          = {10.5281/zenodo.<record-id>},
  url          = {https://doi.org/10.5281/zenodo.<record-id>}
}
```

Replace <record-id> with your minted Zenodo record identifier.

## Citing manuscript materials

If journal policy requires software and manuscript citation separately, cite:

- the software archive (GitHub or Zenodo), and
- the manuscript or preprint when available.
